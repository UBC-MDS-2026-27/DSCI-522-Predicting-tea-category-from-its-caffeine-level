# Contributing

Thanks for checking out our project! If you find a problem or have an idea, feel free to let us know.

## Reporting Bugs

If something is not working, open a GitHub issue. Tell us what went wrong and how we can find the same problem. Screenshots or error messages would also help.

## Suggesting Changes

Have an idea to make the project better? Open an issue and tell us about it. A short explanation is enough.

## Contributing Code

If you want to make changes, please follow these steps:

1. Create a new branch from `main`.
2. Make your changes and test your code.
3. Commit your work with a clear message.
4. Open a pull request and link the issue.
5. Ask a teammate to review your changes.

Please don't push directly to `main`. At least one teammate needs to review the pull request before merging.

## Using AI

You can use tools like ChatGPT or Claude to help with code, writing, or fixing errors.

If you use AI, make sure you understand and check the results. Please mention what tool you used and what you used it for in your pull request. We will also record AI use in the README.

Issues and pull requests must be opened by people, not AI tools. Teammates must also handle the reviews and merges themselves.
